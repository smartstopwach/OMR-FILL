# OMR Fill

Android-first OMR answer-sheet website. Tap **A / B / C / D** bubbles for each question number,
keep an **Answer Key**, and get an instant **Result** (score, correct / wrong / skipped, accuracy, CSV export).

No build step, no dependencies — plain HTML, CSS and JavaScript.

## Features

- **OMR sheet**: question rows with big tap-friendly bubbles (4 or 5 options), tap again to clear.
- **Answer key tab**: fill the correct answers the same way, then results are matched automatically.
- **Paste answers**: paste `ABCDABCD`, `1A 2B 3C` or `1-A,2-C` to fill many questions at once.
- **Results**: marks with negative marking, score ring, stacked breakdown, question-wise table.
- **Flags & filters**: mark questions for review; filter All / Pending / Review; jump to Q#.
- **Undo** (up to 100 steps), clear, reset.
- **Timer**: elapsed time, or a countdown with auto-submit when time is up.
- **Auto-next**: after filling, the sheet scrolls to the next question.
- **Instant check** (settings toggle): ON karne par jaise hi answer bharo, sahi option hara aur galat laal ho jaata hai, aur sahi option ka ring dikhta hai. Answer key bhari honi chahiye. OFF par sheet normal rehti hai.
- **Settings switches**: dark/light theme, sound on tap, vibration, auto-next.
- **Export & share**: CSV download, native Android share sheet, print / save as PDF.
- **Installable PWA** with offline support (service worker) — "Install" from Chrome's menu on Android.
- **Multiple mocks**: "Mocks" tab se naya mock (Mock 1, Mock 2, ...) banao. Purana mock safe rahta hai. Kisi bhi mock ko open, rename ya delete kar sakte ho.
- **Per-question time**: har question par lagaa time record hota hai. Result mein time chart aur slowest question dikhta hai. Time = ek question par tap se agle question par tap tak ka gap (3 min se zyada idle gap ginte nahi).
- **Score chart**: Mocks tab mein sab mocks ka score bar chart mein dikhta hai.
- Everything is saved in the browser (localStorage, key `omrfill:v2`). Purana single-sheet data apne aap "Mock 1" mein migrate ho jaata hai.

## Run locally

Serve the folder with any static server (service workers need `https` or `localhost`):

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# open http://<your-ip>:8080 on your Android phone (same Wi-Fi)
```

| --- | --- |
| `index.html` | Page structure |
| `styles.css` | Mobile-first styles, dark/light themes, print styles |

| `manifest.webmanifest` | PWA manifest |
| `icons/` | App icons (generated by `scripts/make-icons.js`) |

## Scoring

`Score = Correct × marks_per_correct − Wrong × negative_per_wrong`
Skipped questions score 0. A question that has an answer but no key entry is shown as "No key" and is not scored.
